##  What makes it different?

This portfolio isn't designed to be a long page that you keep scrolling through.

Instead, it uses a **minimal floating navigation system** on the side.

Hover over an icon - its name appears.

Click an icon - its dedicated page opens.

Simple. Clean. Easy to navigate.

### Small details matter.

*  Separate pages instead of one long scrolling page
*  Responsive layout
*  Floating icon-based navigation
*  Hover labels
*  Active-page indication
*  Light / Dark mode
*  Mobile-friendly navigation
*  Semantic HTML structure
*  No external framework

##  Responsive by Design

The website is designed to work across different screen sizes:

```text
📱 375px       Mobile
      ↓
📱 768px       Tablet
      ↓
💻 1280px+     Desktop
```

The goal wasn't just to make it *look good on my laptop*.

It should feel comfortable wherever it is opened.
